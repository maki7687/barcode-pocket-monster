# 👾 Barcode Pocket Monster (Barcode Monster Deck)

**Barcode Pocket Monster** 是一款基于 HTML5 与 JavaScript 开发的轻量级、无需后端的 Web 扫码怪兽对战与收集游戏。玩家可以扫描现实生活中的任何条形码（或手动输入条码文本），将它们转化为独一无二的怪兽，体验收集、PVP 模拟对战与 PVE 副本闯关的乐趣。

---

## ✨ 核心特性

* 📦 **万物皆可扫 (Barcode Engine)**：通过扫描或输入任意条形码（EAN-13、UPC、CODE128 等），算法会自动解析条码 Hash，生成独一无二的怪兽。
* 🎲 **丰富且严谨的属性生成系统**：
  * **5 种稀有度**：`N` / `R` / `SR` / `SSR` / `UR`。
  * **5 大职业类型**：刺客 (ASSASSIN)、坦克 (TANK)、战士 (WARRIOR)、法师 (MAGE)、恶魔 (DEMON)。
  * **8 大元素属性**：🔥 火系、💧 水系、⚡ 雷系、🌿 草系、💀 暗系、✨ 圣系、🌋 岩系、🌪️ 气系（包含完密的元素克制链）[cite: 10]。
  * **品质与资质系统**：从平庸、优秀到史诗、神话，附带随机词条与多重属性加成[cite: 10]。
* ⚔️ **实时模拟对战 (PvP & PvE)**：
  * 支持自定义双人对战演练[cite: 10]。
  * 引入了真实的攻速、闪避、暴击、真实伤害、生命回复以及多种状态异常（灼烧、冰冻、减速）[cite: 10]。
  * 完整的战斗日志与浮动伤害数字动画，并在赛后生成多维度数据统计表[cite: 10]。
* 🗡️ **PVE 副本闯关与玩家成长**：
  * 提供普通、困难、噩梦三种难度挑战，击败守护者与 Boss 关卡升级玩家等级[cite: 10]。
  * 玩家等级提升后将全面按比例强化背包中的所有怪兽[cite: 10]。
* 📖 **种族 × 元素 × 稀有度 组合图鉴**：自动记录收集进度，支持按状态、稀有度、元素及种族过滤检索[cite: 10]。
* 📸 **怪兽高清卡片导出**：集成了 `html2canvas` 与 `JsBarcode`，可一键生成并下载高质感的精致怪兽卡片[cite: 10]。
* 💾 **本地离线存储**：所有怪兽背包数据与闯关进度均自动持久化保存在浏览器 `localStorage` 中，即开即玩[cite: 10]。
